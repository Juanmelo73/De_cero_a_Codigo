# Club de Programacion: De Cero a Codigo

Repositorio con los ejercicios y practicas trabajados en el Club de Programacion **De Cero a Codigo**.

## Contenido

- `ejercicios/`: ejercicios introductorios de programacion.
- `factorial/`: practicas relacionadas con factoriales y numeros primos.
- `practice-1/`: practicas iniciales con JavaScript.
- `Project_calculator/`: proyecto web de una calculadora.

## Proyecto independiente

La carpeta `Project_calculator/` contiene un proyecto que cuenta con su propio repositorio de GitHub y su propio historial de cambios. Se incluye aqui como parte del material trabajado en el club, pero se mantiene como un proyecto independiente.

Puedes consultar su documentacion especifica en el [repositorio de Project_calculator](https://github.com/Juanmelo73/Project_calculator).

## Tecnologias

Los ejercicios utilizan principalmente:

- Python
- Dart
- JavaScript
- HTML
- CSS

## Como usar este repositorio

Clona el repositorio y abre las carpetas de los ejercicios que quieras revisar. Los archivos HTML pueden abrirse directamente en un navegador y los archivos Python o JavaScript pueden ejecutarse con sus respectivos entornos.
